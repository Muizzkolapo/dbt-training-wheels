What it does with them
  1. 01

    Reads the SQL

    Separates the tables your script reads from the tables it builds. Nothing is written anywhere.

  2. 02

    Proposes the layers

    Each part of the script is placed in staging, intermediate or mart, and given a model name.

  3. 03

    Asks you the things it cannot know

    What each model is for, how dbt should build it, how you want to select it later.

  4. 04

    Opens the pull request

    Pushed with your own SSH key, on a branch, authored by you. Someone still has to review it.

This runs on your machine. Your SQL is not sent anywhere — the only thing that leaves is the branch you push on the last step, and nothing is written to git before then.
