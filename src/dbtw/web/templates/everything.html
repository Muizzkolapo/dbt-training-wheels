{# Every question and every model on one screen -- the design's workbench, and the other half of its Mode toggle: "same conversion, everything on one screen, none of this column." What this replaces is the *asking*: a screen per question, and the describe screen. It does not replace the screens that report what the conversion did. Reading is not the part a comfortable reader wants collapsed, and "Decided for you", "What changed" and "Files" say the same things in both modes because they are the same conversion. Each question that has a worked example shows it here, folded shut under "See the example". The example is the single most effective element the walkthroughs measured -- five of five named it unprompted. A link to the question's own screen was here before, and it never showed the example: in direct mode that screen sends the reader back to this one. Folded, because eight tables open on one screen is the wall this screen exists to avoid. A question the engine draws no example for offers none, and no link to one. Every question and every model carries an id, and a save comes back to it: `/everything#question-` after an answer, `/everything#model-` after a save. A redirect to the top made the reader scroll back down after every press. A refused save comes back here too, beside its model, with what the reader typed in the boxes. Those values are the reader's own text, held for one render, and are an identifier for the reason a saved description is. #} {% extends "base.html" %} {% from "example.html" import example_table %} {% block main %}
